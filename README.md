# Project 21: Professional Scraper

این پروژه بخشی از مسیر Python → AI است و به‌صورت ساده و قابل اجرا نوشته شده است.

## اجرا

```bash
python main.py
```

## وابستگی‌ها

اگر `requirements.txt` خالی نیست:

```bash
pip install -r requirements.txt
```
